Flagship project · LLM security

LLM Security Red-Team Platform

An automated framework that attacks LLM applications the way a real adversary would, then scores how well they held up.

  • Runs prompt injection, jailbreak and sensitive data leakage attacks against a locally hosted Llama 3 model
  • Maps every attack to the OWASP Top 10 for LLM Applications
  • Scores each response as safe or compromised and logs every attempt
  • FastAPI service with a Streamlit results dashboard, packaged in Docker
View code Live dashboard

The problem

Companies are shipping LLM chatbots fast, but most have no repeatable way to check for prompt injection or data leakage before release.

Why it matters

Prompt injection is ranked the number one risk for LLM applications by OWASP. Everything runs locally, so no test data leaves the machine.

AI Vulnerability Prioritization Platform

Security teams can't patch every CVE. This pipeline pulls CVEs from the NVD, enriches them with EPSS scores and CISA KEV exploitation status, and uses an XGBoost classifier to rank them by how likely they are to be exploited, not just by CVSS score. Deployed as a Streamlit app on AWS EC2.
